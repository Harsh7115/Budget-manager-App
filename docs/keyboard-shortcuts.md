# Keyboard Shortcuts

Quick-reference for all keyboard shortcuts available in Budget Manager App.

---

## Global Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl + N` | Add new expense |
| `Ctrl + S` | Save / export data |
| `Ctrl + Z` | Undo last action |
| `Ctrl + Q` | Quit application |
| `F1` | Open help / documentation |
| `F5` | Refresh current view |
| `Escape` | Close dialog / cancel action |

---

## Navigation

| Shortcut | Action |
|---|---|
| `Ctrl + 1` | Switch to Dashboard tab |
| `Ctrl + 2` | Switch to Expense Tracker tab |
| `Ctrl + 3` | Switch to Budget Manager tab |
| `Ctrl + 4` | Switch to Reports tab |
| `Ctrl + 5` | Switch to Settings tab |
| `Alt + Left` | Previous tab |
| `Alt + Right` | Next tab |

---

## Expense Tracker Panel

| Shortcut | Action |
|---|---|
| `Ctrl + N` | Open Add Expense dialog |
| `Delete` | Delete selected expense |
| `Ctrl + E` | Edit selected expense |
| `Ctrl + F` | Focus search / filter field |
| `Ctrl + A` | Select all expenses in table |
| `Enter` | Confirm selection / open detail |
| `Ctrl + I` | Import expenses from CSV |
| `Ctrl + X` | Export expenses to CSV |

---

## Budget Manager Panel

| Shortcut | Action |
|---|---|
| `Ctrl + B` | Add new budget category |
| `Delete` | Remove selected category |
| `Ctrl + R` | Reset budget to defaults |
| `Ctrl + Up` | Increase selected budget by $10 |
| `Ctrl + Down` | Decrease selected budget by $10 |

---

## Reports Panel

| Shortcut | Action |
|---|---|
| `Ctrl + P` | Print current report |
| `Ctrl + Shift + E` | Export report as PDF |
| `Ctrl + Shift + C` | Export chart as PNG |
| `Ctrl + Left` | Previous month |
| `Ctrl + Right` | Next month |
| `Ctrl + Home` | Jump to current month |

---

## Table Navigation (all data tables)

| Shortcut | Action |
|---|---|
| `Up / Down` | Move row selection |
| `Page Up / Page Down` | Scroll table by one page |
| `Home` | Jump to first row |
| `End` | Jump to last row |
| `Ctrl + C` | Copy selected cell value |
| `Tab` | Move to next editable cell |
| `Shift + Tab` | Move to previous editable cell |

---

## Dialog Shortcuts

| Shortcut | Action |
|---|---|
| `Enter` | Confirm / OK |
| `Escape` | Cancel / Close |
| `Tab` | Move to next field |
| `Shift + Tab` | Move to previous field |

---

## Tips

- All shortcuts follow standard **Swing** key binding conventions and can be remapped in **Settings → Keyboard**.
- On macOS, replace `Ctrl` with `Cmd` where applicable (future roadmap item).
- Shortcuts are disabled when a text input field is focused to avoid conflicts.
